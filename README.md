# Drac2 Tools
A collection of useful helper functions for anyone who wants to build useful and reliable avrae code.

The intended usecase is that other workshops, aliases and gvars should pull in the libraries they require from Drac2 Tools, with the confidence and assurance that it works exactly as intended, quickly and reliably.
## Helper Libraries
The following libraries are available freely for other developers to use in their own projects.
### Libraries for interacting with other workshops
* Bags
* Tools
* Notes
### Libraries for writing avrae commands
* Commands
* Embeds
### Libraries for interacting with base data types in drac2
* Dicts
* Lists
* Strings
### Miscelaneos useful libraries
* Expect
* Random
* Rolls
* Time
